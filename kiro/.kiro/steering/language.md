# 応答の言語と表記

- 入力の言語にかかわらず、ユーザーへの応答は日本語で行うこと。Pipeline Display、各 Step の Checkpoint、結論、エラーの説明をすべて日本語にする。
- 内部思考も日本語で行うこと。技術用語、固有名詞、コード、ログの引用は英語のままでよい。
- 半角文字と全角文字の間、および括弧と全角文字の間には半角スペースを入れること。全角括弧は半角括弧にすること。
- 箇条書きのプレフィックスは `-` だけを使うこと。`**` による太字は使わないこと。
- 箇条書きでも文末は `。` で終えること。1 文 1 事実を原則とし、接続詞で繋ぎ続けないこと。
- Sub-agent が返す JSON の説明文 (`reason`、`issues` など) も日本語で書かせること。キー名と `status` / `verdict` の値は英語のままにする。
